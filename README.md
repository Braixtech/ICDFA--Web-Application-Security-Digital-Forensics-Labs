## 📊 Programme Overview

The **Fellowship in Web Application Security & Digital Forensics** is a comprehensive 12-month programme designed to equip trainees with practical skills in web application security, penetration testing, and digital forensics. The programme is divided into two phases, covering **18 courses** with a total of **88 credit hours**.

### Programme Structure

| Phase | Courses | Focus Area | Status |
|-------|---------|------------|--------|
| **Phase 1** | 9 Courses | Web Application Security & Penetration Testing | ✅ Completed |
| **Phase 2** | 9 Courses | Digital Forensics & Investigation | 🔄 Ongoing |

---

## 📘 Phase 1 — Web Application Security ✅ Completed

### BVWS101 — Foundations of Linux, Networking & Bash Scripting
**Credit Value:** 4 | **Lecture Hours:** 8

This course provides foundational knowledge of Linux operating systems, networking fundamentals, and Bash scripting essential for cybersecurity professionals.

---

### BVWS102 — Web Application Security Essentials
**Credit Value:** 4 | **Lecture Hours:** 8

Introduction to core concepts of web application security, including common vulnerabilities, attack vectors, and security best practices.

---

### BVWS103 — OWASP Top 10 Vulnerabilities & Exploitation Techniques
**Credit Value:** 8 | **Lecture Hours:** 16

In-depth coverage of the OWASP Top 10 vulnerabilities, including exploitation techniques, real-world examples, and mitigation strategies.

---

### BVWS104 — Web Application Security CTF
**Credit Value:** 4 | **Lecture Hours:** 8

Practical Capture The Flag (CTF) challenges to develop hands-on skills in identifying and exploiting web application vulnerabilities.

---

### BVWS105 — Web Application Penetration Testing Methodologies
**Credit Value:** 4 | **Lecture Hours:** 8

Comprehensive training in penetration testing methodologies, including reconnaissance, vulnerability assessment, exploitation, and reporting.

---

### BVWS106 — Secure Coding Practices and Input Validation
**Credit Value:** 3 | **Lecture Hours:** 6

Best practices for writing secure code, focusing on input validation, output encoding, and preventing common injection attacks.

---

### BVWS107 — Compliance, Reporting, and Remediation Strategies
**Credit Value:** 3 | **Lecture Hours:** 6

Understanding compliance frameworks, creating professional penetration testing reports, and developing remediation strategies.

---

### BVWS108 — Web Application Penetration Testing Capstone Project
**Credit Value:** 10 | **Lecture Hours:** 20

Capstone project applying all learned skills to conduct a comprehensive web application penetration test and deliver a professional report.

---

### CSR-001 — Community Development & Social Impact in Cybersecurity I
**Credit Value:** 8 | **Lecture Hours:** 16

Community engagement and social impact initiatives in cybersecurity, promoting awareness and education.

## 🎯 Programme Objectives

Upon completion of this programme, graduates will be able to:

### Web Application Security
- ✅ Identify and exploit OWASP Top 10 vulnerabilities
- ✅ Conduct comprehensive web application penetration tests
- ✅ Implement secure coding practices
- ✅ Create professional security assessment reports
- ✅ Develop remediation strategies for identified vulnerabilities

### Digital Forensics
- ✅ Conduct digital forensic investigations
- ✅ Analyze network traffic and packet captures
- ✅ Investigate computer and mobile device incidents
- ✅ Apply AI techniques in forensic analysis
- ✅ Manage forensic intelligence repositories
