## 📊 Programme Overview

The **Fellowship in Web Application Security & Digital Forensics** is a 12-month programme designed to develop practical, industry-aligned skills in web application security, penetration testing, and digital forensics. The programme is delivered in two phases, comprising **18 courses** and **88 credit hours** of combined lecture and laboratory work.

| Phase | Courses | Focus Area | Status |
| --- | --- | --- | --- |
| **Phase 1** | 9 Courses | Web Application Security & Penetration Testing | ✅ Completed |
| **Phase 2** | 9 Courses | Digital Forensics & Investigation | 🔄 Ongoing |

---

## 📘 Phase 1 — Web Application Security ✅ Completed

### BVWS101 — Foundations of Linux, Networking & Bash Scripting

**Credit Value:** 4 · **Lecture Hours:** 8

Foundational knowledge of Linux operating systems, networking fundamentals, and Bash scripting essential for cybersecurity professionals. Covers shell navigation, file permissions, process management, and basic network configuration.

---

### BVWS102 — Web Application Security Essentials

**Credit Value:** 4 · **Lecture Hours:** 8

Introduction to core concepts of web application security, including common vulnerabilities, attack vectors, the CIA triad, and industry security best practices.

---

### BVWS103 — OWASP Top 10 Vulnerabilities & Exploitation Techniques

**Credit Value:** 8 · **Lecture Hours:** 16

In-depth coverage of the OWASP Top 10 vulnerabilities with exploitation techniques, real-world case studies, and mitigation strategies. Includes SQL injection, XSS, CSRF, broken authentication, and security misconfiguration.

---

### BVWS104 — Web Application Security CTF

**Credit Value:** 4 · **Lecture Hours:** 8

Practical Capture The Flag (CTF) challenges developing hands-on skills in identifying and exploiting web application vulnerabilities within controlled lab environments.

---

### BVWS105 — Web Application Penetration Testing Methodologies

**Credit Value:** 4 · **Lecture Hours:** 8

Comprehensive training in penetration testing methodologies — reconnaissance, vulnerability assessment, exploitation, post-exploitation, and professional reporting.

---

### BVWS106 — Secure Coding Practices and Input Validation

**Credit Value:** 3 · **Lecture Hours:** 6

Best practices for writing secure code. Focus on input validation, output encoding, parameterised queries, and preventing common injection attacks across PHP, JavaScript, and SQL.

---

### BVWS107 — Compliance, Reporting, and Remediation Strategies

**Credit Value:** 3 · **Lecture Hours:** 6

Understanding compliance frameworks (ISO 27001, PCI-DSS, NIST), producing professional penetration testing reports, and developing practical remediation strategies.

---

### BVWS108 — Web Application Penetration Testing Capstone Project

**Credit Value:** 10 · **Lecture Hours:** 20

Capstone project applying the full skill set from Phase 1 to conduct a comprehensive web application penetration test and deliver a professional assessment report.

---

### CSR-001 — Community Development & Social Impact in Cybersecurity I

**Credit Value:** 8 · **Lecture Hours:** 16

Community engagement and social impact initiatives in cybersecurity, promoting awareness, digital hygiene, and education in local communities.

---

## 📗 Phase 2 — Digital Forensics 🔄 Ongoing

### BVDF201 — Basic Computer Skills for Digital Forensics

**Credit Value:** 4 · **Lecture Hours:** 8

Foundational computer skills for digital forensics investigations — file systems (NTFS, FAT, ext4), operating system internals, storage media, and data recovery techniques.

---

### BVDF202 — Basic Networking Skills for Digital Forensics

**Credit Value:** 4 · **Lecture Hours:** 8

## 🎯 Programme Objectives

Upon completion of this programme, graduates will be able to:

### Web Application Security

- ✅ Identify, exploit, and remediate OWASP Top 10 vulnerabilities
- ✅ Conduct comprehensive web application penetration tests
- ✅ Implement secure coding practices and input validation
- ✅ Produce professional security assessment reports
- ✅ Develop practical remediation strategies for identified vulnerabilities

### Digital Forensics

- ✅ Conduct end-to-end digital forensic investigations
- ✅ Analyse network traffic and packet captures
- ✅ Investigate computer, mobile, and IoT device incidents
- ✅ Apply AI/ML techniques in forensic analysis workflows
- ✅ Manage forensic intelligence repositories and evidence chains
